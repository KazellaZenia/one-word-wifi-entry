# One Word for Your Wi-Fi

This entry writes a single word describing my Wi-Fi — **Catfish** — to
`entry.txt` inside the output directory.

Why Catfish? It is the one word that fits this Wi-Fi best: it looks
inviting from the name on the tin, then turns out to be something else
entirely once you connect — slow, slippery, and never quite what it
promised to be. Funny because it is true, and true because it is funny.

## How to run

```sh
MAKEFUN_OUTPUT_DIR=/path/to/output python3 main.py
```

That creates `/path/to/output/entry.txt` containing exactly `Catfish`
(7 characters, no extra words).
